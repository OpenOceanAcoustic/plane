## 本轮交付

- 默认综合视图，宽屏文件夹看板与个人日历并排；窄屏合理布局，不导致全页水平溢出。可切换单独文件夹看板、个人周历，并保留日历选定日期。
- 个人日历支持高度调节及框内滚动，完整展示一天的时间范围。此前整页滚动实现已交付，用户在资源时间轴需求中明确改选可调高度；后续要求见 [资源时间轴规格](resource-timeline-spec.md)。
- 保留 ABCD 与未分类、文件夹排序、事项跨文件夹与状态拖动、键盘操作、项目任务同一身份和状态同步。
- 卡片显示真实项目来源、工作项编号、原优先级和截止日期，以及个人事项类别/说明/可见性；增加真实计划时数和最近安排，明确排期操作。私人事项不补造项目属性。
- 支持个人看板搜索和必要筛选。未安排后续时间以本人全部真实时间块的未来范围判断，不能以当前日历窗口未显示推断。
- 日历创建、拖动、调整、拆分及删除后刷新卡片摘要；项目日期和个人时间块保持独立。
- 修复空白时段拖选的新时间块预览崩溃。临时选区事件尚无持久事项，渲染应使用日历原生日期；结束选择后打开安排表单。
- 团队排期继续读取已保存时间块。负责人可查看；私人事项与无权访问任务仅显示忙碌；成员只修改本人安排，未排期事项不进入团队日历。

## 数据与验收

本人 planner 接口增量扩展原任务元信息及批量排期摘要，不复制任务。既有日历颜色发布通过增量迁移 `0005_timeblock_color` 为时间块新增可选颜色及数据库取值约束，历史时间块默认按类别着色；当前时间轴增量没有新增迁移。摘要为本人真实记录，上海本周分钟按周边界裁剪，重叠按计划时间块分别计入；后续时间块为结束时间晚于当前时刻，包含进行中。

复用已确认的 API 与浏览器测试边界。首先以真实 FullCalendar 空白时段拖选重现崩溃，localhost 与普通非回环 HTTP 均失败，再验证修复；另覆盖综合布局、筛选与真实卡片、日期保留、保存后摘要刷新、拖动与拆分、团队隐私。使用隔离数据，保留正式账号与凭据。完成类型、Lint、生产构建、规格/规范两方面评审，备份后更新内网服务并提供新 PR。
