- 个人日历支持高度调节及框内滚动，完整展示一天的时间范围。此前整页滚动实现已交付，用户在资源时间轴需求中明确改选可调高度；后续要求见 [资源时间轴规格](resource-timeline-spec.md)。
- 保留 ABCD 与未分类、文件夹排序、事项跨文件夹与状态拖动、键盘操作、项目任务同一身份和状态同步。
- 卡片显示真实项目来源、工作项编号、原优先级和截止日期，以及个人事项类别/说明/可见性；增加真实计划时数和最近安排，明确排期操作。私人事项不补造项目属性。
- 支持个人看板搜索和必要筛选。未安排后续时间以本人全部真实时间块的未来范围判断，不能以当前日历窗口未显示推断。
- 日历创建、拖动、调整、拆分及删除后刷新卡片摘要；项目日期和个人时间块保持独立。
- 修复空白时段拖选的新时间块预览崩溃。临时选区事件尚无持久事项，渲染应使用日历原生日期；结束选择后打开安排表单。
- 团队排期继续读取已保存时间块。负责人可查看；私人事项与无权访问任务仅显示忙碌；成员只修改本人安排，未排期事项不进入团队日历。

## 自定义事项类别与颜色板（2026-10-09）

本次增量基线 `884c88157620a043e70fcd2fc0511caef6113c57`。用户确认：每个人在当前工作区维护自己的类别。原“项目任务、科研、学习、带教”作为可编辑的初始记录，前端按接口显示类别名称及其配色，不显示颜色名称下拉框。

- 类别支持新增、改名、修改默认颜色和删除；本人工作区范围隔离，同名在本人工作区内不能重复。删除保留事项和时间块，类别回到未分类，不自动重新生成已删除的默认类别。
- 新增及编辑个人事项、引用项目任务均可选择本人类别。类别不决定项目任务身份、权限或原状态；搜索、卡片、类别图例和事项类别图表读取当前真实名称。
- 类别和单个时间块使用常用色块加浏览器颜色板，支持任意六位 RGB 色值。勾选“跟随事项类别”使用类别默认色，单独取色取消跟随；恢复跟随时清空颜色覆盖。
- 普通个人日历、事项时间轴和团队两种排期视图统一使用类别默认色／时间块覆盖。文件夹分组标记继续保留自己的色标与折叠、显示筛选、排序、未排期事项等操作。此要求替代上一轮事项时间轴时间块按文件夹着色的规则。
- 默认排期随类别改色更新；手动颜色在类别修改、拖动、调整、拆分及重载后保留。文字自动按背景选深色／白色以保持可读。
- 私人及无权访问的任务对其他人仅为中性忙碌块，不返回类别 ID、名称、默认色或手动色。接口、图例、图表、下钻及导出继续执行同一规则。
- 增量迁移 `0006_personal_categories` 新增个人类别及可空事项关联，将旧类型关联到初始类别，将旧手动色转成对应 RGB 色值。历史任务、时间及版本保留。升级前备份数据库、附件与独立认证密钥，并在隔离数据库验证旧数据迁移。此迁移不能无损反向映射新增类别及任意色值，回退使用升级前备份。

继续使用已确认的 API 合约与实际浏览器操作测试边界，验证本人类别管理、项目引用、跨用户／工作区拒绝、删除不丢数据、任意取色与自动跟随、私密图表和导出。部署仍使用既有内网地址，保留认证机制与现有业务；GitHub hook 继续搁置。
