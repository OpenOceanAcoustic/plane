# 个人规划工作台完善与周历修复

基线：`46036ac092306ed258a38b506f94c5faadf891e5`，已由 PR #1 合并到 `ooa/main`。开发分支：`feat/personal-planning-workbench`。

用户确认个人规划优先采用“文件夹看板＋周历并排，增强任务卡片”。另报告电脑 Edge 在内网 HTTP 访问中点击周历控件导致 Plane 通用错误页面。GitHub 联动已明确搁置。

## 本轮交付

- 默认综合视图，宽屏文件夹看板与个人日历并排；窄屏合理布局，不导致全页水平溢出。可切换单独文件夹看板、个人周历，并保留日历选定日期。
- 个人与团队日历默认采用紧凑的 520px 高度，支持底边拖动、键盘及数值调整（320–1200px）、重置；日历内部滚动，外层页面仍可滚动。综合和单独模式共享尺寸，按工作区、本人及个人/团队范围在浏览器中记住高度。
- 排期按类别默认配色：项目蓝、科研紫、学习绿、带教橙；每个时间块可选择蓝、紫、绿、橙、粉、青，或恢复按类别。颜色保存到数据库，移动保留，拆分继承；团队中隐藏的内容统一使用中性色，接口不返回私人颜色。
- 保留并集成当前事项时间轴：文件夹/事项行，文件夹展开折叠及显示筛选；个人和团队时间轴支持日/周/月范围。文件夹色标独立于时间块的类别/手动颜色。
- 保留 ABCD 与未分类、文件夹排序、事项跨文件夹与状态拖动、键盘操作、项目任务同一身份和状态同步。
- 卡片显示真实项目来源、工作项编号、原优先级和截止日期，以及个人事项类别/说明/可见性；增加真实计划时数和最近安排，明确排期操作。私人事项不补造项目属性。
- 支持个人看板搜索和必要筛选。未安排后续时间以本人全部真实时间块的未来范围判断，不能以当前日历窗口未显示推断。
- 日历创建、拖动、调整、拆分及删除后刷新卡片摘要；项目日期和个人时间块保持独立。
- 修复空白时段拖选的新时间块预览崩溃。临时选区事件尚无持久事项，渲染应使用日历原生日期；结束选择后打开安排表单。
- 团队排期继续读取已保存时间块。负责人可查看；私人事项与无权访问任务仅显示忙碌；成员只修改本人安排，未排期事项不进入团队日历。

## 数据与验收

本人 planner 接口增量扩展原任务元信息及批量排期摘要，不复制任务。本轮增量迁移 `0005_timeblock_color` 为时间块新增可选颜色及数据库取值约束，历史时间块默认按类别着色。摘要为本人真实记录，上海本周分钟按周边界裁剪，重叠按计划时间块分别计入；后续时间块为结束时间晚于当前时刻，包含进行中。

复用已确认的 API 与浏览器测试边界。首先以真实 FullCalendar 空白时段拖选重现崩溃，localhost 与普通非回环 HTTP 均失败，再验证修复；另覆盖综合布局、筛选与真实卡片、日期保留、保存后摘要刷新、拖动与拆分、团队隐私。使用隔离数据，保留正式账号与凭据。完成类型、Lint、生产构建、规格/规范两方面评审，备份后更新内网服务并提供新 PR。
