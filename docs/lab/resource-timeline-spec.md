# 个人与团队资源时间轴

需求起点：`c5878bd41336cd3b0c9c28fa5b8e73b965c4a61b`。已集成既有日历高度／手动颜色发布 `0e9eb5ff8f619b61d894eb696f13b7eb53a09ee8`，以此作为最终评审基线。隔离分支：`feat/planning-resource-timeline`，复用既有个人事项和时间块，不复制项目任务。

用户确认：个人时间轴按 A/B/C/D 等文件夹纵向分组，每个事项一行；文件夹使用不同颜色，可选择显示哪些文件夹，并展开／折叠事项。用户随后明确选择“可调高度和框内滚动”，取代此前个人日历整页滚动的要求。

## 功能

- 个人日／周／月历继续保留，新增“事项时间轴”。时间轴提供日／周／月范围，切换布局、日历和时间轴时保留日期与时间轴范围。
- 文件夹保持用户排序，包含未分类；保留无排期事项。不同文件夹分色，所属事项标记和时间块沿用文件夹颜色，文字颜色适配 Plane 的亮／暗主题。超过七种预设色后分配扩展色；普通日历及团队排期保留既有类别色及手动颜色，个人时间轴按文件夹分色，时间轴编辑不清除手动颜色。
- 支持文件夹显示选择与原生组内折叠。显示选择及颜色按浏览器、工作区和个人保存；改名、排序或新建文件夹不改变已有颜色。隐藏文件夹后时间轴及 CSV/JSON 导出过滤对应时间块，不删除事项或排期。
- 在事项行空白时段拖选，安排表单预填该事项；文件夹父行不能创建时间块。保留创建、拖动、调整、拆分、删除、重叠提示及并发版本检查；时间步长十五分钟，不改变项目日期、事项归类或指派。
- 团队继续按成员分行，新增日／周／月范围切换；保留人员分列、成员及项目筛选。仅本人资源行允许创建或修改本人安排，禁止拖动换人。
- 私人或无权读取的事项继续使用服务端忙碌投影。本人无权读取的项目时间块放在中性忙碌行，不丢失，也不推断所属文件夹。页面、工具提示、筛选和导出不补充隐藏详情。
- 日历／时间轴高度默认 520px，可输入或拖动调整至 320–1200px，支持键盘调节及按用户／工作区保存；框内滚动查看完整时间范围和事项行，时间轴横向滚动保留。

## 验收

真实 FullCalendar 浏览器测试覆盖文件夹层级、颜色及显隐、原生折叠、事项行预填、时间步长、跨人拖动拒绝、拖动／调整／拆分、日期范围和筛选、忙碌投影及 CSV/JSON；既有日历交互与高度调节一并回归。只使用隔离浏览器夹具，不使用正式成员凭据。
