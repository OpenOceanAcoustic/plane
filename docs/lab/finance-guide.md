# 项目奖励预测、真实资金与悬赏操作说明

入口：工作区侧栏“资金与奖励”和“悬赏大厅”。项目不录入或展示合同／资助总额。所有人民币数值与 VC 分开记账。

## 分笔到账与删除

在“真实余额与到账”点击“登记一笔到账”，选择原阶段并录入本次到账、成本、核准 D、来源和凭证。后续到账继续选择同一阶段，每笔独立分池并保留事实时间、登记时间和原始凭证；页面汇总有效到账的笔数、金额及核准 D。分笔到账不会自动追加个人应付，仍需负责人确认最终累计金额。

每笔记录提供“删除到账记录”，填写删除原因后确认。误录删除通过新增反向流水撤销本笔余额，原记录保留，可勾选“显示已删除记录”查看；其他批次不重写、不重新分池。若本笔风险金已有后续处理，或撤销将侵占已核准奖励、支付安排或已使用资金，窗口提示具体原因，需先处理对应后续事项。

“预算与参考预测”中的阶段卡片提供“删除阶段预算”；选择项目后顶部提供“删除资金项目”。资金项目删除仅停用本项目的资金配置，原生项目及工作项继续保留。删除前需处理相关实际余额、未付核准、现金安排和未结束悬赏；历史公式、预测、VC、凭证、结算及流水不覆盖。删除后不再允许在对应资金配置新增业务。

勾选“显示已删除记录”可选择已删除资金项目并点击“恢复资金项目”，或在阶段卡片点击“恢复阶段预算”。恢复保留原配置和历史，不重新入账或重新分配资金；资金项目需先恢复，才能继续办理其阶段事项。

## 项目负责人：配置预算与公式

1. 在“资金与奖励”选择本项目，点击“设置 VC 预算”，填写预算名称和 VC 额度。最新一笔 VC 预算作为该项目当前发布预算；页面分别显示预算、已占用和剩余。旧预算及其悬赏、贡献、奖励记录保留，新预算不合并或转移旧额度。
2. 需要预计人民币奖励时，办理“冻结阶段奖励预算”，输入该预算对应的执行奖励预测金额 E 和用途条目；用途合计须等于 E。配置成员的基础份额 b、职责份额 r 和计划 VC，未编列部分不会自动平均分配。发布悬赏本身不要求配置人民币奖励预算。
3. 打开“项目奖励公式”，分别填写**任务预计奖励**和**成员阶段预计奖励**。模板仅提供起点；不同项目可以采用完全不同的表达式。任务卡不重复包含每人的基础／职责阶段奖励。
4. 支持四则运算、括号和 `min`／`max`。内置参数为 E、VC、B、b、r；自定义工时、单价、绩效系数须注明作用范围、单位、来源，可设置默认值。内置权威参数不能由普通参数覆盖。
5. 先填写样例试算，再注明变更原因保存新版本。缺失参数、除零、负数或无效表达式会明确报错。保存版本不改变旧预测、最终核准或付款安排。
6. “保存参考测算”会冻结当时的公式版本、输入及输出。预算测算使用阶段 E 和计划 VC；到账测算使用本阶段已核准实际奖励额度及实际 VC。两者都仅为参考，**不自动生成应付或付款授权**。

资金和 VC 输入超出所选账户、批次、付款安排或悬赏的可用额度时，填写过程中立即显示错误并禁用保存／发布；更正金额后恢复。切换项目或资金来源会更新上限。累计核准、扣缴和累计贡献也按各自上下限校验。提交时仍会核查最新余额和权限，以处理他人同时办理导致的余额变化。

## 到账、最终核准与分期付款

负责人登记本项目实际到账、成本扣除、核准分配额度 D、来源与凭证。D 必须有真实资金支撑；资金分为未来项目 15%、公共贡献 10%、风险准备金 5%、成员激励 70%。升级项目的成员部分继续分为历史孵化 10% 和执行 90%；分池不足一分的尾差保留在原资金账户。已经扣除的成本不再重复登记支出。

执行奖励由负责人输入**个人阶段累计最终核准金额**及绩效依据，可关联一笔成员阶段参考预测。页面展示预测、最终金额及差额。金额合计不得超过实际阶段执行奖励额度，也不能降到已付及未取消付款安排以下。后来到账不会自动追加个人应付，需要负责人明确追加累计核准金额。

付款分两步：先安排付款，占用实际可承诺余额；再登记已经在线下发生的支付。每笔记录分别保存应付、扣缴和实付，并关联支付凭证／流水号。已有安排只占用剩余未付部分，重复提交同一请求不会重占或重复付款。未付安排可以取消，已付部分保留。系统不发起银行转账。

期初准备金和历史资金须注明原来源与凭证；导入保留批次以支持原批次释放和历史资格追溯，不重新分池。

录错资金事实时，使用“追加冲正”并说明凭证；原记录保留。已经被后续付款、承诺或核准使用的资金不能直接冲走，须先按事实处理依赖事项。累计最终核准调整使用新一条核准记录，不改写旧记录；公式变更不自动补付或追回。

## 准备金、历史奖励和公共池

准备金按原到账批次显示余额、实际责任支出和释放。退款／返工责任支出须提供用途及凭证。释放回原阶段，不再次提取反哺比例；执行部分可增加可分配额度，但个人奖励仍须负责人确认追加。升级历史部分继续按原批次冻结的资格计算。

升级阶段历史资格记录有效 VC、资金来源、资格起始日期及证据，由冻结 VC 计算份额，资格窗口为 36 个日历月。后续同来源分期沿用原分母和份额，过期部分不重新分给其他人；不同后续来源须明确记录可继承关系和依据。历史核准使用独立动作，普通执行预测公式不改变资格。

公共池由指定的工作区管理员管理；页面可明确变更管理员。未来池年度新增资金编列为研究 70%／探索 30%，探索奖励可拨入已冻结阶段，不再分池。月度公共职责采用固定金额核准、付款安排和线下支付，成员只能查看自己的明细。争议预留和未用奖励结转都有独立动作，不能动用已核准、已承诺的奖励。留存资金可以拨入本项目的其他冻结阶段作为执行奖励额度，不再次分池；接收阶段的个人最终金额仍须另行核准。

管理员办理年度编列时，年度未来池可编列额度由服务端按工作区时区计算，扣除已经编列的额度并排除已冲正记录。即使某笔资金来自管理员无权查看明细的项目，也计入正确的年度汇总；项目源记录仍按原权限隐藏。按项目筛选不会缩小公共未来池的年度额度。选择其他年度后，输入上限随该年度的可编列额度更新。

## 悬赏认领、共享资料与配色

负责人点击大厅“发布悬赏”，选择项目及该项目的可发布工作项，填写 VC 配额、任务资料、交付要求、验收标准和验收人。工作项自动列出，不必先搜索。资料填写一次，同时用于公开摘要及执行资料。原生新项目首次发布会自动建立工作状态映射，使用原有待做、进行中和完成状态；缺少独立验收状态时追加“待验收”。已有人工映射不改动。重大任务显示“复核人”字段；现金承诺、预计人天和安全事项放在“更多设置”。

发布直接占用“资金与奖励”中该项目当前 VC 预算，剩余不足不能发布，也不会回退使用旧预算或借用其他项目。尚未设置预算时，使用发布窗口中的“资金与奖励”入口跳转到资金页。大厅不再提供冻结阶段预算、WIP 管理或账本入口。WIP 表示同时进行中的任务数量，现有并行任务限制继续生效。

发布人、验收人和重大任务复核人可以选择同一名有效项目成员。重大任务仍须分别办理发布复核和验收复核，每一步单独留痕；不会因为角色相同自动通过。验收／复核人员不能认领该任务的分工，也不能验收自己参与的团队任务。

大厅默认展示开放认领卡片，可切换“我的待办／我的参与”。公开摘要对实验室成员可见；旧悬赏保留原项目可见范围，由负责人显式发布公开摘要后开放全员浏览。

成员申请 → 负责人批准 → 本人确认 → 团队开工。确认后自动加入本人规划，不覆盖已有文件夹、类别和配色。跨项目参与仅授权该任务；执行资料由负责人在详情面板明确共享附件或文档版本，撤回共享后立即停止读取，不自动授予整个项目访问权。

认领窗口的可用 VC 为悬赏总配额减去所有已经批准的分工计划配额，由服务端返回；待批准申请尚不占用配额，已授予贡献不会重复扣减。公开大厅只显示总剩余额度，不公开其他成员的分工资料。计划 VC 超过剩余额度时立即提醒并禁用保存。发布或认领遇到并发余额变化被拒绝时，窗口刷新额度并保留已填资料，可更正后重试。验收中的个人累计通过 VC 不能超过计划配额，也不能低于此前已授予的贡献。

大厅、个人规划、日历及原生看板显示类别颜色和彩色描边、实心星、“悬赏”标记。日历时间块自定义覆盖色继续保留；无权查看的事件仅显示中性“忙碌”。任务卡显示 VC、参考预计金额及公式版本；尚未配置公式或缺参数时显示原因。

指定验收、重大任务发布复核和重大验收复核继续执行，并保留各节点权限和办理记录。资金最终核准由项目负责人办理，不替代任务验收流程。

负责人可在悬赏详情点击“删除悬赏”并填写原因。删除后大厅移除卡片、撤回任务授权及共享资料、释放未授予的 VC；原工作项、个人规划、排期、配色和已有贡献及付款记录保留。误发布的原工作项可再次发布。历史 VC 的冲正入口继续按当前负责人权限提供。

在个人规划点击项目工作项卡片，打开 Plane 原生右侧总览，可查看属性和活动并按原权限编辑。个人事项及仅有任务授权的跨项目悬赏也在右侧打开；后者只显示获准的任务资料，撤权后不复用执行资料缓存。

## 流程、查询与导出

项目、任务和资金流程图分别关联源记录；阶段及到账批次可并行。点击节点查看办理人、记录日期、事实日期、变更依据、公式／测算快照、凭证和源记录；有权用户可以从节点打开对应业务表单。归档与财务结清分别显示，归档不会自动结清应付、风险准备金或扣缴。

悬赏图默认显示紧凑主流程，重大任务仍包含所需复核节点，相关异常及历史分支按当前记录展示。点击“全部流转”查看所有可用流转，点击“主流程”恢复简洁视图；“当前阶段”定位到当前办理节点。切换显示方式不会改变办理步骤、权限或历史记录。

“资金与奖励”的“账目明细”显示人民币资金流水，“VC 明细”提供贡献账本、冲正和 CSV／JSON 导出。两种账目均可按项目筛选，导出范围与页面权限一致。补录事实日期和记录日期分别保留。旧历史只依据已有项目、悬赏和账本恢复，不编造过去审批或现金记录。
