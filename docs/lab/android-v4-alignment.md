# Android 1.0.2：V4 视觉与操作对齐

基准为用户指定的 `http://127.0.0.1:4318/index.html?v=4&reload=vertical-tables#biz-analytics-vc`，以及同一 V4 图集的其余页面。截图中的旧 APK 把全部模块铺在首页，字号、行高、导航、表格与图表均偏离设计；此次按原图集的组件、页面结构和操作位置重新实现。参考文件与 220 个设计状态的指纹保存在 [参考清单](android-v4-reference.json)，实际接口与操作入口保存在 [功能映射](android-screen-coverage.md)。参考图的示例记录不进入产品包。

## 页面与共用组件

- 首页恢复工作台、两条个人工作入口与便签，应用按“更多”页面分组；用户卡展示真实账号、工作区和角色。
- 共用 V4 的 Inter 字体、线性 SVG 图标、原便签空态图片、浅深色变量、字号、行高、间距、边框和圆角。页内仅保留一处标题；使用 Android 的实际系统栏、键盘与安全区。
- 项目、任务、五种任务视图、任务详情、六项属性、活动时间线、评论栏与状态面板保留真实接口；概览“添加任务”位于设计中的顶部按钮，列表创建位于浮动按钮。
- 排期的统计、标签、文件夹、日历与时间轴按设计排列；规划和悬赏详情使用完整页面，编辑和办理操作使用底部面板。跨页面查看悬赏后返回会恢复原排期上下文，可见嵌套面板优先处理返回键。
- 资金与统计使用设计中的标签、摘要、彩色图表及纵向记录。表格的全部字段逐项展示；月历完整适配屏宽。跨月热图按七天分组纵向展示，避免把数十天压在屏宽内。
- 个人资料、主题偏好、通知、文档、组件排序、快捷链接与其它业务页面使用共用组件。拖拽与键盘排序采用相同的相邻中点规则。

资金小数、请求幂等键、排期版本检查、权限、协作文档票据和附件处理继续使用原接口。统计日期输入为包含结束日，传给后端时转换为独占结束边界；“查看贡献明细”指向参与者贡献而非预算记录。统计范围说明和手动时区设置保留。

## 以最新用户范围为准

God Mode 的七个移动设计示例已明确排除。手机没有管理员入口、路由或登录，后端拒绝新旧 Android 管理会话与借普通 Android 会话请求电脑管理接口。电脑网页 `/god-mode/` 保留管理员登录。服务器 SSH 创建首位管理员、生成一次性成员邀请链接；Lab 模式关闭旧邮件邀请入口和接口。工作区角色管理和添加已有工作区成员到项目继续可用。

手机数据导出仍被禁止，普通查询、授权附件下载及文档同步保留。

## 实际检查与验收边界

用户要求自行测试，本次未执行业务测试、单元测试、APK 安装或模拟器测试。执行的检查为 TypeScript、Lint、格式、Web/APK 构建、签名和 manifest 校验，以及只读浏览器视觉呈现。规范与规格双评审发现的排序、日期、贡献明细、时区与返回导航问题已修复；原问题和修复记录放在独立交付目录。

只读对照使用实际移动前端组件和隔离的展示数据，所有写请求被拦截；不接触运行实例的账户或业务数据。13 个主要页面分别以 360/412 CSS px、浅/深色呈现，共 52 组对照；另保留核心页面 20 组和认证页面对照。52 组呈现没有 JavaScript 报错、横向溢出、未知读取路径或写请求，且深色截图确认实际使用深色主题。对照去掉图集中的模拟系统栏，按相同可用尺寸比较内容，Android 系统栏仍由系统绘制。

对照目录：`/mnt/repo/ly/android-delivery/v4-visual-alignment/`。其中 `visual-report.json`、`capture.cjs`、PNG 和 `index.html` 为独立检查材料，不打包到 APK。不同项目、记录数、人员、角色、时间与权限显示以真实响应为准。截图呈现不能替代真实业务操作、全量设计状态或 Android 设备验收；最终验收标准仍是操作和视觉与 V4 一致，由用户安装本次 APK 后执行。
