# 实验室协作功能完善与图表增强

**Status:** ready-for-agent

## Problem Statement

实验室已经使用基于 Plane v1.4.2 的 Community Edition Fork 管理账号、项目、个人事项、排期、悬赏和 VC。现有规划交互较简单，缺少完整的资源日历、依赖联动、自定义字段、实验文档关联和可核查的统计图表。用户要求在现有框架上完整实现这些功能，统一原有风格，免费自托管，保留全部已有数据和认证规则。

## Solution

采用已经确认的九阶段交付：个人文件夹、个人日历、团队排期、自定义字段、项目甘特、实验文档、悬赏流程图、十二张图表、集成部署。每阶段交付完整 API、页面和行为测试。继续使用 Django/DRF、PostgreSQL、原生 Plane 用户/权限/任务/文档；新增表通过增量迁移引入。

## User Stories

1. 作为成员，我可以建立、改名、排序和删除 ABCD 文件夹，以组织本人任务。
2. 作为成员，我可以拖动或用键盘把事项移动到文件夹，刷新后仍保留位置。
3. 作为成员，我删除文件夹时，事项回到未分类，原项目任务不受影响。
4. 作为成员，我可以引用跨项目任务，并查看其同步的原状态。
5. 作为成员，我可以新增科研、学习和带教事项，决定是否公开详情。
6. 作为成员，我可以按日、周、月查看自己的计划，默认按周查看。
7. 作为成员，我可以创建、拖动、调整和拆分时间块，以十五分钟为步长。
8. 作为成员，我保存重叠时间块时收到提示，并可以保留安排。
9. 作为成员，我保存过期版本时收到冲突提示，不覆盖较新的修改。
10. 作为负责人，我可以按人员分列查看团队日历。
11. 作为负责人，我可以按横向人员时间轴查看一周排期。
12. 作为负责人，我可以按人员、项目和日期筛选可见安排。
13. 作为成员，我的私人事项及他人无权访问的任务只显示忙碌时间。
14. 作为管理员，我可以定义八类工作区自定义字段。
15. 作为项目负责人，我可以选择本项目启用哪些字段。
16. 作为项目成员，我可以编辑有权限任务的字段，停用字段后历史值仍保留。
17. 作为项目成员，我可以筛选、排序、分组任务表格，调整显示列和导出数据。
18. 作为项目成员，我可以通过甘特图查看日期、依赖及未排期任务。
19. 作为项目成员，我可以调整任务日期并预览受到影响的后续任务。
20. 作为项目成员，我确认后才保存联动，数据变化时必须重新预览。
21. 作为项目成员，我无法建立自身依赖或循环依赖，也不能联动无权限任务。
22. 作为研究成员，我可以从实验记录模板建立项目文档。
23. 作为研究成员，我可以将任务与同项目文档双向关联，并上传附件。
24. 作为研究成员，我可以查看及恢复文档版本，私有文档受同样权限保护。
25. 作为悬赏参与者，我可以查看流程当前节点、历史和本人可执行动作。
26. 作为负责人或验收人，我从流程图执行操作时仍受预算、WIP 和独立验收规则约束。
27. 作为成员，我可以查看真实项目数据图表并点击进入对应任务。
28. 作为负责人，我可以查看计划排期、重叠和忙碌统计，但不能从图表推断私人内容。
29. 作为项目成员，我可以查看本项目预算、贡献、冲正和验收统计。
30. 作为成员，我可以导出图表 PNG 及 CSV/JSON，导出范围与页面权限一致。
31. 作为系统管理员，我可以升级、备份及验证恢复，保留认证、任务、附件和贡献记录。

## Implementation Decisions

- 前端采用 dnd-kit、Frappe Gantt、FullCalendar 7.1.1、TanStack Table、shadcn/ui 源码适配、已有 Tiptap、React Flow 和已有 Recharts。使用包管理器指定版本和 catalog，统一 Plane 主题，保留第三方许可。
- FullCalendar 资源日历与时间轴使用全栈 AGPL 开源授权，公开对应源代码入口；不用付费订阅、试用密钥或第三方云服务。
- 文件夹为扁平错位页签，保留未分类。任务引用原生 Issue，排期和任务日期相互独立。
- 日历默认 Asia/Shanghai、周一开周、十五分钟步长；事件结束为排他边界。成员只编辑本人排期；服务端生成脱敏忙碌事件，筛选与导出不得透露隐藏内容。
- TimeBlock 新增 revision；修改、删除、拆分提交 expected_revision，在事务锁内核对并递增，冲突返回 409。
- 字段支持 text、number、single_select、multi_select、date、member、boolean、url；管理员定义，负责人选择启用。首轮可选字段，停用保留值，不提供公式和跨表关联。
- 项目甘特仅项目内联动，使用原生 IssueRelation 的 blocked_by 关系作为完成后开始依赖。日期为包含首尾的自然日；后续最早在前置结束次日开始，保留后续时长，仅顺延违规任务。
- 日期联动由后端计算预览，显式确认后事务提交，检查任务、关系版本及权限，写原生任务活动和审计。拒绝自身/循环依赖、缺少日期及无权访问/修改的影响范围；不能静默修改跨项目节点。
- 文档复用原生 Page、ProjectPage、PageVersion 和附件；实验模板包含目标、方法、配置、结果、结论、后续事项。新增明确的 TaskDocumentLink，不能用内容引用 PageLog 代替手工关联。
- React Flow 是现有悬赏流程的投影；动作复用现有接口，不新增第二套可变流程状态或审批引擎。
- 新接口统一置于 /api/workspaces/{slug}/lab/，复用现有会话和服务端项目权限。

### 十二张预设图表

| 类别 | 图表                                                                |
| ---- | ------------------------------------------------------------------- |
| 项目 | 状态分布、项目完成率、新增与完成日期趋势、逾期任务分布              |
| 排期 | 成员每周计划时数、每日排期热力图、事项类别占比、重叠时间分布        |
| VC   | 阶段预算占用、项目内成员计划与实际 VC、授予与冲正趋势、验收结果分布 |

图表支持筛选、下钻和 PNG、CSV/JSON 导出。排期表示计划投入；重叠另行统计。完成日期取当前原任务记录，不补造历史。预算为当前余额，不受日期区间裁切。VC 按项目展示，无全局排名。空数据为空状态，无模拟数据。

## Testing Decisions

- 已由用户确认的测试边界为业务 API 与浏览器操作；优先使用现有 DRF APIClient、真实隔离 PostgreSQL 和 Playwright。测试外部行为、真实权限和事务结果，不耦合私有实现。
- 逐条 red/green 验证文件夹持久化、状态同步、时间块边界和冲突、服务端隐私、八类字段校验、甘特 DAG/预览/并发回滚、文档版本/附件/关联权限、悬赏与账本原有约束、图表源数据/下钻/导出。
- 回归原邀请/TOTP/重放/限流/恢复/项目上传，运行完整后端测试、前端类型/Lint、串行应用构建、Chromium 操作和备份恢复验证。
- 所有测试使用隔离环境；不修改当前成员账号、邀请、认证密钥或业务记录。
