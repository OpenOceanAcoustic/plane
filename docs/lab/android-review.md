# Android Standards and Spec reviews

Both read-only reviews compared implementation commit `c078463d5d` against pinned baseline `98c234c4227e5265cb3f2a97ab3ae4469c67af1c`, using [the approved specification](android-app-spec.md). The reviewers were independent sub-agents; subsequent fixes are part of the delivery branch.

## Standards

| Finding                                                                                                      | Resolution / verification                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Three passages narrated backend behavior, permissions or document workflow, violating AGENTS.md product copy | Removed the Gantt/template instructions; replaced permission explanation with the factual “无权访问” status.                                                                                                                 |
| Native failures discarded exception diagnostics                                                              | Native transport logs only operation, error category and exception class; session storage has a distinct error category. No message, stack, URL, credentials or request contents are logged. RED→GREEN native failure tests. |
| Judgment: separate Sheet/LabDialog back implementations had diverged                                         | Both now consult one DOM-based top-dialog helper; Back/Escape consumes only the visible sheet. A submitting FormSheet blocks dismissal. Browser regression first reproduced the nested-close defect.                         |
| Judgment: unconstrained route strings can fall through to personal settings                                  | Unknown routes now display a missing-page state. A full discriminated route union is a future refactor, not a release requirement.                                                                                           |

The reviewer found no additional substantiated native credential-isolation or Live-ticket security breach.

## Spec

| Finding                                                                                        | Resolution / verification                                                                                                                                                                                                                              |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Editing a project could erase its existing description                                         | Read full detail before editing, with loading/error guards; write the authoritative PATCH response back into the detail cache. Actual backend regressions verify rename retention and immediate consecutive edits, including a delayed background GET. |
| Project view offered private visibility although backend ignores access and defaults to shared | Removed unsupported access mutation; record displays backend visibility.                                                                                                                                                                               |
| An account without workspaces could not reach personal settings/God Mode/Space                 | Workspace-empty guard applies only to workspace pages; explicit independent-page entry points are present. Browser fixture uses an empty membership response without deleting actual memberships.                                                      |
| Initial concern: intake alias is read-only in the serializer                                   | Real endpoint inspection found the view explicitly accepts legacy `inbox_view`; the initial finding was a false positive. The final API accepts canonical `intake_view` with legacy alias compatibility, and actual PATCH/GET verifies behavior.       |
| Unlocking a locked document retained a read-only ticket                                        | Lock/access changes recreate the provider and obtain a fresh single-use ticket; editing authority stays disabled until renewed.                                                                                                                        |
| Space properties read nonexistent object fields                                                | Resolve actual `state_id`, `assignee_ids`, `label_ids` against public state/member/label endpoints.                                                                                                                                                    |
| Project overview opened personal settings                                                      | Use the `project-settings` route.                                                                                                                                                                                                                      |
| Lab pages stayed stale after foregrounding                                                     | Native resume dispatches an event subscribed to by Lab planner, market and resources; reconnect also refreshes. Browser regression first reproduced stale data.                                                                                        |
| Back could dismiss several sheets or an in-flight save                                         | Shared top-dialog check and busy dismissal guard; regression covers both.                                                                                                                                                                              |
