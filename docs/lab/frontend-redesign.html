01 / Principles

先定规则，再画界面

每个界面都必须回答同样四个问题：Scope 是什么、当前视图是什么、实体是什么、操作结果在哪里反馈。

01

一个 Scope

项目、成员、日期、搜索进入 URL。切换板块、刷新、分享、前进后退都保留上下文。

useLabScope()
02

一套控件

以 Propel 为基座，只保留一种密度、一种焦点、一种菜单行为。不再出现原生 select 与自建弹窗并存。

Propel + Lab wrappers
03

一个实体

卡片、日历事件、表格行、资金记录都打开同一个实体面板，关联对象在面板内一跳可达。

LabEntityPanel
04

一种反馈

loading / empty / error / toast 四态统一。后台轮询只显示“同步中”，不阻塞任何操作。

LabAsync
05

颜色有语义

9 个标签族按类别、状态、角色、资金科目分配。同一屏最多三组语义色，不用颜色做装饰。

8 label families + blue
06

密而不挤

13px UI 基线、8px 网格、表面层级最多两层。用间距和分隔线替代卡片套卡片。

13px / 8px grid

01

文件夹是颜色索引

A/B/C 与未分类各有一个色点，同时出现在文件夹标签、卡片 pill 和周历事件上；色点只代表文件夹，不抢状态色。

02

卡片只保留一个主动作

“安排时间”是行内的主动作；编辑、移动、移除收进同一个菜单，避免每张卡上出现三四个同级按钮。

03

空态也是设计

空列给出简短说明和拖入提示，不写管理政策。空态、错误、加载都走同一个 LabAsync 组件。
