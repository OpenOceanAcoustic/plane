# Android V4 screen coverage

The 220 V4 design examples are mapped below to real mobile routes and their forms/sheets. These are functional mappings, not 220 separate activities or a claim that each example was manually checked on every Android version. The prototype atlas and its demonstration records are not packaged in the APK.

Source: approved V4 `android-ui-prototype/manifest.json`, revision 4, 2026-10-10. All `src/` paths below are relative to `apps/mobile`. Workspace-relative paths have prefix `/api/workspaces/{slug}` unless stated otherwise.

Detailed contracts and validations: [core](android-core-coverage.md), [planning/bounty/finance/analytics](android-lab-coverage.md), [workspace](android-workspace-coverage.md), [settings](../../tools/mobile/settings-coverage.md), [backend capabilities](../../apps/api/docs/mobile-api.md).

CSV/JSON/XLSX/chart-image/document/configuration export actions are deliberately absent from mobile. Ordinary queries, collaboration binary synchronization and authorized existing attachment downloads remain available. UI and server export restrictions remain enforced. New business and device testing is delegated to the user; the latest visual checks use read-only fixture data.
