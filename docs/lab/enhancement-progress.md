## 回归修复与双轴评审

[规格评审](enhancement-review-spec.md)与[代码规范评审](enhancement-review-standards.md)分别检查当前改动。发现的 P2 项均已修复，最终无实质规格或规范阻断；CSV 序列化去重为可选 P3 维护建议。

回归覆盖了筛选后旧图表导出、跨周时数、有效 0% 完成率、重大必经复核、字段逆序响应及开关失败回退、Frappe 实例清理、文件夹菜单关闭和原生字段精确标签。真实浏览器验收过程中发现并修复了这些可操作性问题；尾斜杠匹配及键盘拖动的渲染帧等待属于测试定位/时序修正。原 Vite 8 / Rolldown 构建链复现随机原生 Oxc 崩溃，单独更换压缩器未完全解决。最终固定 React Router 7.17 明示兼容的 Vite 7.3.7，使用 Rollup / esbuild 保持生产压缩；新工具链下四应用串行构建、26 项类型/Lint、12 项组件及 4 项完整服务浏览器均通过。正式服务随后核对了三处认证入口及项目上传。
