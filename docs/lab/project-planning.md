# 项目规划（多层甘特）

项目规划页把项目工作项按父子关系排成树，左侧是层级表格，右侧是按开始/截止日期绘制的时间轴，整体参考 PingCode 规划页的信息密度。

## 层级

- **阶段**：有子项的项目顶层事项，靛蓝色，左侧粗色条与浅色底。
- **任务组**：有子项的非顶层事项，紫色，缩进一级。
- **任务**：没有子项的普通事项，橙色，更深一层的缩进。
- **子任务**：第三层及更深的叶子事项，粉色，字号更小、颜色更淡。
- 每层都有独立的行底色、左侧色条、层级徽标、时间轴条高度和颜色；顶部有图例。
- 有子项的行可以展开/收起；父行没有日期时，用子项的最早开始和最晚截止作为汇总条，虚线描边。
- 未排期事项在时间轴左侧显示灰色虚框。

## 数据

- `GET /api/workspaces/{slug}/lab/projects/{projectId}/gantt/` 增加 `parent_id`、`assignee_ids`、`assignee_names`、`priority`。
- 查询预取 `assignees`，避免逐条查询。
- 前端 `LabGanttTask` 增加对应的可选字段；原生 Frappe 甘特图继续兼容旧字段。

## 页面

- 顶部项目选择、总数/已排期/未排期/阶段统计、周/月时间尺度、刷新、打开工作项。
- 项目左侧导航增加「项目规划」，与工作项、周期、模块等入口并列。
- 左侧固定列：编号、标题、负责人、开始、结束、状态；标题列含展开按钮、层级图标和层级徽标。
- 右侧时间轴：月份分段、每周刻度、今天虚线、阶段/任务组/任务/子任务四色条。
- 悬停工作项行尾出现 `+`；点击在下方展开输入框，Enter 创建子工作项，Esc 取消。
- 快捷键：`N` 新增（行上新增子项，空白处新增根工作项）、`↑↓` 选择行、`→` 展开、`←` 收起、`Enter` 打开工作项。
- 负责人列显示首字母头像；新增时输入框保持打开，可连续添加多个子项。
- 点击行或时间轴条打开工作项；父行展开/收起不触发打开。
- 窄屏下表格和时间轴在同一个横向滚动容器内，页面本身不产生横向溢出。

## 部署

本次包含 API 序列化字段，安装器会先执行 Django 检查，再重启 `api` 容器，然后构建并发布 Web：

```bash
sudo python3 /tmp/deploy-project-planning.py
```

前端构建产物需要包含 `lab-planning-table-row`；安装器会在发布前校验。
