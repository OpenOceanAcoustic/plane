# 实验室协作首版规格

基线：Plane Community Edition v1.4.2（5f7d92784c403f76284f0f16718f320221dc7fec）。组织分支 `ooa/main`；实现分支 `feat/lab-planning-bounty-auth`。

## 认证

仅 SSH 管理命令签发邀请、初始化管理员、撤销邀请及恢复账号。邀请随机 token 只保存 SHA-256，24 小时过期、单次消费，预览不消费。用户名忽略大小写，姓名和联系邮箱是资料；邮箱无需验证。绑定本地二维码并确认六位 TOTP 后，事务内创建用户、成员和加密凭据。账号没有可用密码。登录仅用户名加动态码，30 秒周期、前后一步容差，禁止重复时间步。每账号滚动十分钟五次请求（含成功），第六次 429；持久化计数并串行处理同账号并发。关闭所有旧注册、密码、魔术邮件、OAuth 和网页管理员初始化入口，包括 Space。恢复立即吊销凭据、会话和 API 令牌，一次性链接重新绑定原用户。停用账号拒绝登录。认证秘密不进入日志或遥测；Fernet 密钥独立备份。

后端提供 `sh backend.sh`，运行即在终端直接输出首次管理员的一次性注册链接，支持成员邀请、撤销和恢复，不生成注册链接文件。主应用、管理员和 Space 的登录页只显示标题、用户名、动态码、登录按钮与必要的状态反馈；移除内部成员政策等说明小字。

## 规划

个人工作区文件夹默认 A/B/C/D，可以新增、改名、排序和删除；删除后内容未分类。项目任务保持同一 Issue 身份、权限和状态，也支持私人科研、学习和带教事项。周历支持多个时间块、拖动、缩放和拆分；安排不修改原任务起止日期。负责人查看团队安排，成员只能编辑本人安排；私人内容由服务端隐藏，其他人只见忙碌，本人可公开。中文、上海时区、周一开周、15 分钟步长；重叠提示但可保存。

## 悬赏与贡献

项目负责人冻结阶段预算 B、发布团队任务卡并批准认领和指定独立验收人。团队任务预算 T 占用 B；交付物、分工、计划 VC、验收条件开工前确认。进行中 WIP 每人最多两项，重大最多一项，覆盖原生任务入口；例外记录原因、批准人、失效时间。重大：>=40 VC、>20% B、>=5000 元新承诺、>10 人日或重大路线/安全事项；发布和验收均独立复核。验收通过/部分通过/返工/不通过，符合约定的有效探索负结果可通过。普通/重大分别三个/五个工作日到期；超期提醒而不自动通过。VC 给实际参与者，复验只加差额、请求幂等、更正追加冲正，负责人不自动提成。账本保存人员任务快照，删除归档后可核查。项目内展示，不做全局排名。现金计算/支付和历史孵化结算不在首版。

## 架构与交付

独立 Django lab 模块，共用 PostgreSQL、用户、会话和项目权限。认证 `/auth/lab/`，业务 `/api/workspaces/{slug}/lab/`。复用 Plane UI 和资产；侧栏个人规划、团队排期、悬赏大厅。任务四类状态：待做/进行中/待验收/完成。站内待办和 CSV/JSON 导出。

本机开发 web 3000/admin 3001/API 8010/附件 9100、9190；最终入口默认 localhost:8080，持久卷、串行构建。按用户选择启用内网入口 `192.168.137.90:8080`，仅入口 8080 监听 0.0.0.0，其余端口保持回环或不暴露。注册链接、前后端和 CORS 使用同一实际访问地址，切换配置保留已有数据和认证密钥。团队正式使用启用 HTTPS。交付 PR、启动停止、SSH 管理和备份恢复说明。

## 验收

邀请过期/撤销/复用/并发只消费一次；未绑定和全部旧入口不能绕过；动态码有效/错误/过期/复用；五次请求的并发、边界、换 IP、重启；恢复和停用；任务状态同步、拆分、服务端隐私；并发 WIP/B/T；禁止自验收、重大独立复核、部分通过和重复请求不重复授予。Django/pytest、类型检查、Lint、串行构建、关键浏览器流程及数据库/附件/密钥恢复验证。
