# 我的项目与 VC

入口：工作区侧栏“我的项目与 VC”。

页面顶部显示本人在当前工作区的累计获得、累计冲正和个人净 VC。个人净 VC 为验收入账减去冲正，项目和月份筛选不会改变这个全时期总额。计划配额、预计奖励和人民币付款不属于这项总额。

“参与项目”包括当前已加入项目、已批准且本人确认的跨项目悬赏项目，以及有个人贡献记录的历史项目。没有入账的项目显示 `0.00`；同一个项目只显示一次。单纯申请但尚未确认的悬赏不计入参与项目。

在“VC 日历”选择月份和项目。每格按项目汇总当天获得和冲正；点击日期查看当天符合项目筛选的流水，点击项目日汇总则筛选到当天该项目的流水。“清除选日”恢复整月明细，“加载更多”读取下一页。

日期按上海时区的实际 VC 入账时间显示。冲正在更正发生当天显示负数，原获得日期仍保留正向入账，因此跨月更正不会重写以前的日期。

点击流水可查看本人的入账摘要。当前有项目权限的源任务使用 Plane 原生右侧总览；跨项目悬赏仅开放受控任务详情和明确共享的资料。退出项目、撤销任务授权或删除源工作项后，本人的金额和项目/任务快照继续保留，源资料不会因历史账目重新开放。

月份或项目切换时会重新加载月历和明细。读取失败可使用“刷新”重试；筛选不会隐藏或扣减顶部的个人历史净 VC。
