## 实现

默认综合工作台，宽屏看板／周历并排，窄屏上下排列；支持单独模式和保留日期。增强任务来源、编号、优先级、截止日、个人说明、可见性、计划时数和最近安排，并增加搜索、项目／状态及待排筛选。

本人 planner 批量读取有权限的原任务和真实时间块。当前上海周分钟按边界裁剪，重叠分别计入，进行中和远期安排均计入后续安排。项目及卡片查询不随数量逐项增长，无数据库迁移。

周历崩溃根因为 FullCalendar 临时选区事件没有持久的 `extendedProps.block`。在空白时段拖选时，原渲染读取 `block.title` 抛出异常并触发整页错误边界。现在使用原生临时事件日期，选择结束后正常打开安排表单。回归先在 localhost 和普通 HTTP 两种源上复现失败，再验证修复。

保存、移动、调整、拆分和删除会刷新卡片摘要；成功保存后先关闭表单，再读取刷新，避免读取失败时重复创建。planner 请求序号防止旧轮询覆盖最新摘要，延迟响应测试先复现 `60 !== 120` 的错误，再验证保护生效。
