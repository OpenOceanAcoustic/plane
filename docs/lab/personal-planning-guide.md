# 个人规划工作台

工作区侧栏进入“个人规划”。默认“综合”模式：宽屏左侧文件夹看板、右侧个人周历；窄屏上下排列。上方可切换“文件夹看板”或“个人周历”，切换不会重置日历日期。

日历随页面可用空间自动调整高度，内容在控件内滚动，可以查看晚间时间段和更多事项。页面不再提供像素高度输入或手动高度拖动条。

“事项时间轴”按文件夹分组，每个事项一行。同一事项的多个时间块显示在同一行；文件夹标记保留分组颜色，时间块按事项类别或单独选择的颜色显示。点击文件夹前的箭头展开／折叠，使用“显示文件夹”选择需要展示的分组；未排期事项仍保留一行。在事项行空白时间拖选会直接预填该事项。日／周／月按钮调整时间轴范围。默认“总览”将当前范围放进可见宽度，使用放大／缩小按钮查看细节；放大后可以横向滚动，点击“总览”重新回到完整日期范围。

个人日历、事项时间轴与团队排期统一使用事项类别默认色，也允许每段排期单独取色。 下方图例读取当前可见时间块的实际颜色；默认配色标注类别，单独配色标注“类别 · 事项（单独配色）”，忙碌时间使用中性色。日期、项目及文件夹筛选后图例同步变化。

点击上方“管理类别”新增、编辑或删除自己的类别。“项目任务、科研、学习、带教”为初始类别，可改名及改色。类别仅属于本人当前工作区。删除类别保留事项和排期，显示“未分类”；不会重新生成已删除类别。

创建或编辑事项时使用“事项类别”选择，引用的项目任务同样可以选类别。类别只影响分类与默认配色，原项目任务的身份、状态及权限仍保留。

类别表单和排期表单都提供常用色板及“自定义取色”，点击取色框打开浏览器颜色板。排期勾选“跟随事项类别”时随类别改色；点击色块或自定义取色后成为单独配色，再勾选即可恢复默认。拖动、调整和拆分会保留单独配色。

## 事项和安排

- “个人事项”创建所选自定义类别的安排，默认私人；“引用项目任务”引用原工作项，状态变化同步到原项目。
- 文件夹默认 A/B/C/D，可拖动、键盘排序及改名。拖动卡片到文件夹改变归类，拖到状态列改变状态；删除文件夹保留事项和时间块。
- 从卡片上的拖动手柄拖到目标状态列，也可直接使用卡片的状态选择框。未配置状态映射的项目，待做、进行中和完成自动使用原项目的对应状态；状态同步到原工作项并记录活动历史。
- 项目任务进入“待验收”前，负责人需在项目设置中新增独立的进行中状态，再用“项目状态映射”选择四个不同状态。保存失败会在视口内显示原因，卡片保留原状态；自动刷新不会清除该通知。
- 项目卡片显示项目名、原任务编号、优先级及截止日；点击标题或时间轴事项名打开 Plane 原生任务详情侧栏，查看说明、附件、属性和活动。个人卡片／时间轴事项名与时间块点击显示事项详情，包含完整说明、类别、状态、文件夹和当前安排；在详情内选择“调整时间块”或“安排时间”。时间块右上角也有独立的调整排期按钮。
- “安排…”打开当前事项的时间表单，也可在日历空白处拖选时间并选择事项。支持日／周／月、拖动、调整时长、拆分及删除，按上海时间和十五分钟步长保存。
- 卡片显示本周计划时数和下一次安排，保存排期后同步刷新。顶部“本周计划”始终统计上海当前周，切换日历日期不会改变这一含义；重叠时间块分别计入计划投入。
- 看板可以搜索标题、说明、任务编号和项目，按项目、状态筛选。“只看待排事项”显示未完成且没有进行中或未来时间块的事项，查阅其他周不会影响判断。

## 团队可见性

保存的个人时间块自动进入“团队排期”，未排期事项不显示。管理员与负责人按现有权限查看团队；成员只能维护本人安排。

团队“人员时间轴”按成员分行，支持日／周／月范围，也可切换“人员分列”。使用人员、项目和日期筛选查看安排；时间块只能调整时间，不能拖动到其他成员行。

私人事项默认向其他人显示“忙碌”，公开事项可展示内容；项目任务仍遵守项目和工作项权限。隐私规则在接口、图表及导出中同样执行。个人排期不改变项目任务的甘特日期。

## 运行与验证

入口：[内网服务](http://192.168.137.90:8080)。更新后浏览器刷新页面；如保留旧页面，可用 `Ctrl+F5` 重新载入。

```bash
tools/lab/lab.sh start
tools/lab/lab.sh stop
tools/lab/lab.sh status
node tools/lab/test-planning-store.mjs
pnpm exec playwright test --config tools/lab/browser/playwright.config.ts
```

邀请码及账号恢复继续使用 `./backend.sh`，不更改已有账号。启停、邀请、认证密钥备份及隔离恢复步骤见 [部署说明](README.md)。本次应用 `0006_personal_categories` 增量迁移，旧类别和颜色自动转换，既有项目、事项、排期、悬赏和 VC 保留。
